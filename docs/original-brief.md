Build a premium Windows desktop application called **Raspberry**.

Raspberry is a modern terminal and system administration workspace inspired by the polish of Warp Terminal, Windows Terminal, VS Code, and enterprise monitoring dashboards. The application is intended for developers, power users, and IT administrators managing their own computers and authorized networks.

## Core Goals

* Extremely polished UI
* Native-feeling performance
* GPU accelerated animations
* Modular architecture
* Easily expandable tool system
* Beautiful dark glassmorphism design
* Raspberry-red branding
* Clean, maintainable code
* Production-quality architecture

## Architecture

Use a fully modular plugin architecture.

Every tool should exist as its own module with clearly separated:

* UI
* Services
* State
* Commands

Adding a future tool should require minimal code changes.
